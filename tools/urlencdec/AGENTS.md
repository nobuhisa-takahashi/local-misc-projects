# AGENTS.md — urlencdec

URLエンコード/デコードを行うコマンドラインツール。
zsh関数版、Rust版、Go版の3実装を提供する。

## 仕様

- コマンド名: `urlencdec`
- 標準入力から文字列を受け取り、変換結果を標準出力に出力する
- デフォルト動作: URLエンコード
- `-d` オプション指定時: URLデコード
- エンコード方式: RFC 3986 準拠（英数字と `-._~` 以外をパーセントエンコード）

## 使用方法

```
echo "文字列" | urlencdec       # エンコード
echo "%E6%96%87" | urlencdec -d  # デコード
```

## 実装別ルール

### zsh関数版 (`zsh/`)

- 高級言語 (Python 等) は使用しない
- zsh 組み込み機能と標準コマンドのみ使用する

### Rust版 (`rust/`)

- Cargo プロジェクトとして構成

### Go版 (`go/`)

- Go モジュールとして構成

## 開発環境

- Rust / Go のバージョンは `.tool-versions` でローカル管理
- ビルド後のバイナリ配置はユーザーが手動で行う
